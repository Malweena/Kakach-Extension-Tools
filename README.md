Kakach Extension Tools
=====================
***
Возможности скрипта остались такими же как и в 1chan Extension Tools, но с некоторыми обновлениями и нововведениями:
* Быстрая вставка картинок теперь с имгуря вместо рыгхоста
* Пофикшены протухшие пиктограммы
* В панель смайлов добавлены все новые смайлы (включая те, которых официально нету на Какаче)
* Допиленная карта ответов с рабочим предпросмотром
* Починенное скрытие постов с менее чем 140 символами
* Добавлены опциональные кнопки навигации по странице (вверх / вниз)
* Исправлены косяки интерфейса
* Исправлены ошибки кода, из-за которых скрипт ломался

Установка
=========
***
Последнюю версию скрипта всегда можно скачать по [этому адресу](https://raw.github.com/Malweena/Kakach-Extension-Tools/master/Kakachuserscript.user.js).
- Если у вас нормальный браузер, то используйте Tampermonkey для установки этого расширения
- Если ваш браузер не поддерживает Tampermonkey, то пора бы его обновить
